# Partner contribution

This project needs one small contribution from another student for the course assignment.

## Suggested change

Pick one visible, easy-to-review improvement, for example:

- add another sample product;
- improve a label or message in the interface;
- add a `description` field to a product;
- improve this documentation.

## Pull Request workflow

1. Fork this repository on GitHub.
2. Clone your fork and create a branch, for example `partner-improvement`.
3. Make and test one focused change.
4. Commit using your own GitHub account and push the branch to your fork.
5. Open a Pull Request to this repository's `main` branch.
6. In the Pull Request, briefly explain what changed and how it was checked.

Please do not commit IDE settings, build output, or the local `data/` database.
